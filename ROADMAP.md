# MARKETFLOW Roadmap

## 🔴 Must Have — MVP

These features are required for the ALG-AUTO-01 core workflow.

- [ ] Visual workflow editor
- [ ] Drag-and-drop nodes
- [ ] Connect nodes
- [ ] Trigger nodes
- [ ] Action nodes
- [ ] Condition nodes
- [ ] Data transformation
- [ ] Workflow validation
- [ ] Actual workflow execution
- [ ] Execution status
- [ ] Execution logs
- [ ] Save workflow
- [ ] Load workflow
- [ ] Basic dashboard
- [ ] Deployed demo

## 🟡 Should Have

Product features that make the MVP feel like a marketing SaaS product.

- [ ] Marketing workflow templates
- [ ] AI workflow generation
- [ ] Workflow search
- [ ] Duplicate workflow
- [ ] Retry failed step
- [ ] Execution history
- [ ] Success/failure analytics
- [ ] Human-readable logs
- [ ] Demo seed data
- [ ] Responsive UI

## 🟢 Nice to Have — Stretch

Only implement after the core demo is stable.

- [ ] Scheduling
- [ ] Webhooks
- [ ] Parallel branches
- [ ] Workflow versioning
- [ ] Approval steps
- [ ] More external integrations
- [ ] Natural-language workflow editing
- [ ] Advanced analytics
- [ ] Team collaboration

## Explicitly Out of Scope for the 24-Hour MVP

- Building dozens of integrations
- Enterprise permissions
- Complex billing
- Production-grade distributed execution
- Full CRM replacement
- Large-scale infrastructure

## Priority Rule

If time becomes limited:

```text
Working execution
      >
Beautiful UI
      >
AI enhancement
      >
Stretch integrations
```

A smaller workflow that actually executes is better than a huge workflow builder that only looks functional.
